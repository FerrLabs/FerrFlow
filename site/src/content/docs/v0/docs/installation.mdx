## Local installation

<Tabs syncKey="install-method">
  <TabItem label="Cargo">
    ```bash
    cargo install ferrflow
    ```
  </TabItem>

  <TabItem label="npm">
    ```bash
    npm install -g ferrflow
    # or as a dev dependency
    npm install -D ferrflow
    ```
  </TabItem>

  <TabItem label="Binary">
    Download a pre-built binary from [Releases](https://github.com/FerrLabs/FerrFlow/releases/latest):

    ```bash
    # Linux x86_64
    curl -L https://github.com/FerrLabs/FerrFlow/releases/latest/download/ferrflow-x86_64-unknown-linux-gnu.tar.gz | tar xz
    sudo mv ferrflow /usr/local/bin/
    ```
  </TabItem>

  <TabItem label="Docker">
    ```bash
    docker run --rm -v $(pwd):/repo ghcr.io/ferrlabs/ferrflow:latest check
    ```
  </TabItem>
</Tabs>

## CI installation

The recommended way to use FerrFlow in CI is the GitHub Action — no installation step needed:

```yaml
- uses: FerrFlow-Org/ferrflow@v0
  env:
    GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

See [GitHub Actions](/v0/docs/ci/github-actions) and [GitLab CI](/v0/docs/ci/gitlab-ci) for complete examples.

## Verify

```bash
ferrflow --version
```

## Installation locale

<Tabs>
  <TabItem label="Cargo">
    ```bash
    cargo install ferrflow
    ```
  </TabItem>
  <TabItem label="npm">
    ```bash
    npm install -g ferrflow
    # ou en dépendance de développement
    npm install -D ferrflow
    ```
  </TabItem>
  <TabItem label="WASM (navigateur)">
    ```bash
    npm install @ferrflow/wasm
    ```

    Utilisez FerrFlow directement dans le navigateur — parsez les commits, calculez les incréments de version et générez des changelogs côté client sans backend.
  </TabItem>
  <TabItem label="Binaire">
    Téléchargez un binaire pré-compilé depuis les [Releases](https://github.com/FerrFlow-Org/FerrFlow/releases/latest) :

    ```bash
    # Linux x86_64
    curl -L https://github.com/FerrFlow-Org/FerrFlow/releases/latest/download/ferrflow-linux-x64.tar.gz | tar xz
    sudo mv ferrflow /usr/local/bin/
    ```
  </TabItem>
  <TabItem label="Docker">
    ```bash
    docker run --rm -v $(pwd):/repo ghcr.io/ferrflow-org/ferrflow:latest check
    ```
  </TabItem>
</Tabs>

## Installation CI

La méthode recommandée pour utiliser FerrFlow en CI est la GitHub Action — aucune étape d'installation nécessaire :

```yaml
- uses: FerrFlow-Org/ferrflow@v2
  env:
    GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

Consultez [GitHub Actions](/fr/docs/ci/github-actions) et [GitLab CI](/fr/docs/ci/gitlab-ci) pour des exemples complets.

## Vérification

ferrflow --version

The FerrFlow MCP server lets AI assistants (Claude, Cursor, Windsurf, etc.) interact with your FerrFlow setup through the [Model Context Protocol](https://modelcontextprotocol.io).

## Installation

<Tabs>
  <TabItem label="Docker">
    ```bash
    docker run -d \
      --name ferrflow-mcp \
      -p 3001:3001 \
      ghcr.io/ferrflow-org/mcp:latest
    ```
  </TabItem>
  <TabItem label="From source">
    ```bash
    git clone https://github.com/FerrFlow-Org/MCP.git
    cd MCP
    pnpm install
    pnpm build
    pnpm start
    ```

    Requires Node.js 22+ and pnpm 9+.
  </TabItem>
</Tabs>

The server starts on port **3001** by default.

## Configuration

The MCP server is configured via environment variables:

| Variable | Description | Default |
|----------|-------------|---------|
| `PORT` | Server listen port | `3001` |
| `API_URL` | FerrFlow API base URL | `http://localhost:3000` |

## Connecting to your AI assistant

### Claude Desktop

Add the server to your `claude_desktop_config.json`:

```json title="claude_desktop_config.json"
{
  "mcpServers": {
    "ferrflow": {
      "url": "http://localhost:3001"
    }
  }
}
```

### Claude Code

```bash
claude mcp add ferrflow http://localhost:3001
```

### Cursor / Windsurf

Add to your MCP settings:

```json title="mcp_config.json"
{
  "mcpServers": {
    "ferrflow": {
      "url": "http://localhost:3001"
    }
  }
}
```

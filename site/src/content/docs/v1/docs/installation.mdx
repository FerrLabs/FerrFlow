## Local installation

<Tabs syncKey="install-method">
  <TabItem label="Cargo">
    ```bash
    cargo install ferrflow
    ```
  </TabItem>
  <TabItem label="npm">
    ```bash
    npm install -g ferrflow
    # or as a dev dependency
    npm install -D ferrflow
    ```
  </TabItem>
  <TabItem label="WASM (browser)">
    ```bash
    npm install @ferrflow/wasm
    ```

    Use FerrFlow directly in the browser — parse commits, compute version bumps, and generate changelogs client-side without a backend.
  </TabItem>
  <TabItem label="Binary">
    Download a pre-built binary from [Releases](https://github.com/FerrFlow-Org/FerrFlow/releases/latest):

    ```bash
    # Linux x86_64
    curl -L https://github.com/FerrFlow-Org/FerrFlow/releases/latest/download/ferrflow-linux-x64.tar.gz | tar xz
    sudo mv ferrflow /usr/local/bin/
    ```
  </TabItem>
  <TabItem label="Docker">
    ```bash
    docker run --rm -v $(pwd):/repo ghcr.io/ferrflow-org/ferrflow:latest check
    ```
  </TabItem>
</Tabs>

## CI installation

The recommended way to use FerrFlow in CI is the GitHub Action — no installation step needed:

```yaml
- uses: FerrFlow-Org/ferrflow@v1
  env:
    GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

See [GitHub Actions](/docs/ci/github-actions) and [GitLab CI](/docs/ci/gitlab-ci) for complete examples.

## Verify

```bash
ferrflow --version
```

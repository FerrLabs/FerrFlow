Le serveur MCP FerrFlow permet aux assistants IA (Claude, Cursor, Windsurf, etc.) d'interagir avec votre installation FerrFlow via le [Model Context Protocol](https://modelcontextprotocol.io).

## Installation

<Tabs>
  <TabItem label="Docker">
    ```bash
    docker run -d \
      --name ferrflow-mcp \
      -p 3001:3001 \
      ghcr.io/ferrflow-org/mcp:latest
    ```
  </TabItem>
  <TabItem label="Depuis les sources">
    ```bash
    git clone https://github.com/FerrFlow-Org/MCP.git
    cd MCP
    pnpm install
    pnpm build
    pnpm start
    ```

    Nécessite Node.js 22+ et pnpm 9+.
  </TabItem>
</Tabs>

Le serveur démarre sur le port **3001** par défaut.

## Configuration

Le serveur MCP est configuré via des variables d'environnement :

| Variable | Description | Défaut |
|----------|-------------|--------|
| `PORT` | Port d'écoute du serveur | `3001` |
| `API_URL` | URL de base de l'API FerrFlow | `http://localhost:3000` |

## Connecter votre assistant IA

### Claude Desktop

Ajoutez le serveur à votre `claude_desktop_config.json` :

```json
{
  "mcpServers": {
    "ferrflow": {
      "url": "http://localhost:3001"
    }
  }
}
```

### Claude Code

```bash
claude mcp add ferrflow http://localhost:3001
```

### Cursor / Windsurf

Ajoutez dans vos paramètres MCP :

```json
{
  "mcpServers": {
    "ferrflow": {
      "url": "http://localhost:3001"
    }
  }
}
```

## Endpoints

| Chemin | Description |
|--------|-------------|
